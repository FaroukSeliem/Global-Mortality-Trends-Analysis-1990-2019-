    📌 Project Overview
    
      This project provides a macro-level investigation into three decades of global health data, covering 204 countries and analyzing over 1.46 billion death records.
      The goal was to synthesize this massive dataset into a scannable, interactive Power BI Dashboard to uncover the primary drivers of mortality and track how causes of death have evolved over time.

    📊 Key Insights
    
      The "Big Three" Killers: Cardiovascular diseases, Neoplasms (Cancers), and Chronic Respiratory diseases consistently rank as the top global causes of death.
      Regional Concentration: Mortality volume is heavily concentrated in China, India, and the United States, driven by both population size and aging demographics.
      Global Health Pressure: Annual deaths have risen steadily from ~44M in 1990 to over 54M in 2019, highlighting the increasing demand for global healthcare infrastructure.

    🛠️ Technical Workflow & ETL
    
      Handling a dataset of this scale (1.4B+ records) required a heavy focus on performance and data engineering:
      Data Sourcing: Extracted longitudinal health datasets from Kaggle.
      ETL & Cleaning (Power Query):
      Performed extensive data transformation and normalization of country names.
      Handled missing values across diverse health metrics.
      Optimization: Optimized data types and schema to ensure the model remained performant and responsive despite the high record count.
      Data Modeling: Established a star schema allowing seamless filtering by year, geography, and specific causes of death.
      Visualization: Designed for scannability using high-contrast KPI cards for immediate insights and dual-axis charts to compare disparate country-level data.
